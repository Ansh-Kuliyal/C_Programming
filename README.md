The `Basic` folder contains my practice programs on:

- Variables and data types
- Format specifiers
- Operators
- User input
- If and switch statements
- Functions
- Loops
- Random numbers
- Arrays and 2D arrays
- Strings
- Ternary operator
- Typedef and enums
- Structures
- Pointers
- File handling
- Dynamic memory allocation
  - malloc
  - calloc
  - realloc
